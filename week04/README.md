## Свързан списък

Структурата от данни _„свързан списък“_ представлява поредица от елементи, като всеки от тях съдържа не само информацията, която бихме пазили в масив, но и информация кой е _следващият_ (и _предишният_) елемент в поредицата.

В най-стандартната имплементация тази информация представлява указател към следващия (и предишния) елемент. Така лесно можем да обходим всички елементи от структурата — започвайки от първия, следваме неговия указател към следващия, оттам към по-следващия и т.н.

Допълнително ще пазим два указателя — към първия и към последния елемент на списъка. Това ще ни позволява лесно да добавяме елемент както в началото, така и в края.

## Едносвързан списък (Singly Linked List)

```text
head
 |
 v
[ 1 ] --> [ 2 ] --> [ 3 ] --> nullptr
```

Всеки възел пази стойност и указател към следващия. От възел не може да се върнем назад.

Реализация: [`SinglyLinkedList.h`](./implementation/SinglyLinkedList/SinglyLinkedList.h)

| Операция                                    | Сложност |
| :------------------------------------------ | :------- |
| Добавяне на елемент на произволна позиция   | O(n)     |
| Добавяне в началото или в края              | O(1)     |
| Премахване на елемент от произволна позиция | O(n)     |
| Премахване от началото                      | O(1)     |
| „Преглед“ на произволен елемент             | O(n)     |
| „Преглед“ на първия или последния елемент   | O(1)     |

## Двусвързан списък (Doubly Linked List)

```text
        head                          tail
          |                             |
          v                             v
nullptr <-- [ 1 ] <--> [ 2 ] <--> [ 3 ] --> nullptr
```

Всеки възел пази и указател към предишния, затова можем да се движим и в двете посоки — и да премахнем елемент от края за O(1).

| Операция                                    | Сложност |
| :------------------------------------------ | :------- |
| Добавяне на елемент на произволна позиция   | O(n)     |
| Добавяне в началото или в края              | O(1)     |
| Премахване на елемент от произволна позиция | O(n)     |
| Премахване от началото или от края          | O(1)     |
| „Преглед“ на произволен елемент             | O(n)     |
| „Преглед“ на първия или последния елемент   | O(1)     |

Тук се появява и най-големият недостатък на списъците в сравнение с динамичния масив. **При списъците губим възможността за директен достъп.** Няма начин, по който да индексираме k-тия елемент, без да минем през всички k-1 предходни.

## Какво е свързаният списък като структура от данни?

Крайна редица от хомогенни елементи. Операциите за включване и изключване са допустими на произволни места в редицата. Възможен е и достъп до всеки елемент в редицата.

![Свързан списък](https://media.geeksforgeeks.org/wp-content/cdn-uploads/gq/2013/03/Linkedlist.png)

## Да си го напишем сами?

Има две основни физически представяния — свързано с една връзка и свързано с две връзки. Връзката между отделните елементи се осъществява чрез указател към следващия елемент. За поддържане на структурата е достатъчен указател към началото на списъка.

## А да го ползваме на готово?

Макар и да го имаме в stl, не го използваме самоцелно поради лошите сложности при добавяне и триене. Повечето задачи използват тънкости при работата с отделните елементи на списъка.

```cpp
#include <list>
// ...
std::list<int> l;
```

# Задачи

### Задача 1. Обръщане на свързан списък

По даден указател към `head` — началото на свързан списък с една връзка, върнете _обърнатия списък_.

![Обръщане на списък](https://assets.leetcode.com/uploads/2021/02/19/rev1ex1.jpg)

```text
Input:  head = [1,2,3,4,5]    Output: [5,4,3,2,1]
Input:  head = [1,2]          Output: [2,1]
Input:  head = []             Output: []
```

**Ограничения:**

- Броят на възлите е в диапазона [0, 5000].
- -5000 <= Node.val <= 5000

Списъкът може да се обърне както итеративно, така и рекурсивно. Реализирайте и двата варианта.

### Задача 2. Цикличен свързан списък

По дадено начало на свързан списък определете дали той има цикъл в себе си.

Свързан списък има цикъл, ако съществува негов елемент, който може да се достъпи повече от веднъж, следвайки указателя `next`, след като сме тръгнали от началото. Функцията да връща `true` или `false`.

![Цикличен списък](https://assets.leetcode.com/uploads/2018/12/07/circularlinkedlist.png)

```text
Input:  head = [3,2,0,-4], pos = 1    Output: true
Input:  head = [1,2], pos = 0         Output: true
Input:  head = [1], pos = -1          Output: false
```

`pos` е позицията, към която сочи последният възел, или -1, ако списъкът няма цикъл. `pos` не се подава на функцията — тя вижда само началото.

**Ограничения:**

- Броят на възлите е в диапазона [0, 10<sup>4</sup>].
- -10<sup>5</sup> <= Node.val <= 10<sup>5</sup>

Може ли да се реши с O(1) допълнителна памет?

### Задача 3. Сливане на два сортирани списъка

Слейте два сортирани свързани списъка в нов **сортиран** списък. Той трябва да бъде построен от вече съществуващите елементи на двата подадени списъка.

![Сливане на списъци](https://assets.leetcode.com/uploads/2020/10/03/merge_ex1.jpg)

```text
Input:  l1 = [1,2,4], l2 = [1,3,4]    Output: [1,1,2,3,4,4]
Input:  l1 = [], l2 = []              Output: []
Input:  l1 = [], l2 = [0]             Output: [0]
```

**Ограничения:**

- Броят на възлите в двата списъка е в диапазона [0, 50].
- -100 <= Node.val <= 100
- И двата списъка са сортирани в ненамаляващ ред.

### Задача 4. Сортиране на свързан списък

По дадено начало на свързан списък с една връзка върнете списъка, сортиран във възходящ ред.

![Сортиране на списък](https://assets.leetcode.com/uploads/2020/09/14/sort_list_1.jpg)

```text
Input:  head = [4,2,1,3]        Output: [1,2,3,4]
Input:  head = [-1,5,3,4,0]     Output: [-1,0,3,4,5]
Input:  head = []               Output: []
```

**Ограничения:**

- Броят на възлите е в диапазона [0, 5 * 10<sup>4</sup>].
- -10<sup>5</sup> <= Node.val <= 10<sup>5</sup>

Може ли сортирането да стане за O(n log n) време и O(1) допълнителна памет?

### Задача 5. Сбор на числа

Дадени са два непразни свързани списъка, представящи две неотрицателни цели числа. Техните цифри са записани в обратен ред и всеки възел съдържа една цифра. Съберете двете числа и върнете резултата като свързан списък.

Можем да предполагаме, че числата не започват с `0`, освен самото число 0.

![Сбор на числа](https://assets.leetcode.com/uploads/2020/10/02/addtwonumber1.jpg)

```text
Input:  l1 = [2,4,3], l2 = [5,6,4]              Output: [7,0,8]      (342 + 465 = 807)
Input:  l1 = [0], l2 = [0]                      Output: [0]
Input:  l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]    Output: [8,9,9,9,0,0,0,1]
```

**Ограничения:**

- Броят на възлите във всеки списък е в диапазона [1, 100].
- 0 <= Node.val <= 9

### Задача 6. Премахване на елемент от свързан списък

Напишете функция, която изтрива елемент на свързан списък с една връзка. Като аргумент на функцията обаче няма да бъде подадено началото на списъка, а самият елемент, който трябва да изтрием.

Гарантирано е, че подаденият елемент не е краят на списъка.

![Премахване на възел](https://assets.leetcode.com/uploads/2020/09/01/node1.jpg)

```text
Input:  head = [4,5,1,9], node = 5    Output: [4,1,9]
Input:  head = [4,5,1,9], node = 1    Output: [4,5,9]
Input:  head = [1,2,3,4], node = 3    Output: [1,2,4]
Input:  head = [0,1], node = 0        Output: [1]
```

**Ограничения:**

- Броят на възлите е в диапазона [2, 1000].
- -1000 <= Node.val <= 1000
- Стойността на всеки възел е уникална.
- Възелът за изтриване е в списъка и не е последен.

### Задача 7. Изтриване на n-тия елемент от края

По дадено начало на свързан списък и число `n` премахнете `n`-тия елемент от края на списъка и върнете началото.

![Изтриване от края](https://assets.leetcode.com/uploads/2020/10/03/remove_ex1.jpg)

```text
Input:  head = [1,2,3,4,5], n = 2    Output: [1,2,3,5]
Input:  head = [1], n = 1            Output: []
Input:  head = [1,2], n = 1          Output: [1]
```

**Ограничения:**

- Броят на възлите `sz` е в диапазона [1, 30].
- 0 <= Node.val <= 100
- 1 <= n <= sz

Може ли да се справите с едно обхождане?

### Задача 8. Изравняване на многослоен двусвързан списък

Даден е двусвързан списък, чиито възли имат указател към следващия елемент, към предишния елемент и един допълнителен указател към наследник (`child`). Този допълнителен указател може да сочи или да не сочи към отделен двусвързан списък от същия вид. Тези списъци могат също да имат наследници и така се образуват много нива.

![Многослоен списък](https://assets.leetcode.com/uploads/2021/11/09/flatten11.jpg)

По дадено начало на първото ниво изравнете списъка така, че всички възли да са в двусвързан списък на едно ниво. Ако `curr` е възел с наследници, в изравнения списък наследниците трябва да се появяват между `curr` и `curr->next`.

Върнете началото на новия списък. Всички указатели към наследници трябва да са `nullptr`.

```text
Input:  head = [1,2,3,4,5,6,null,null,null,7,8,9,10,null,null,11,12]
Output: [1,2,3,7,8,11,12,9,10,4,5,6]

Input:  head = [1,2,null,3]
Output: [1,3,2]

Input:  head = []
Output: []
```
