## Как е организирано repo-то?

```text
weekNN/
├── README.md      # теория, примери и задачи за седмицата
└── *.cpp          # кодът, който писахме на упражнението
```

### Компилиране

```bash
g++ -std=c++17 -Wall -Wextra <file>.cpp -o <file> && ./<file>
```
