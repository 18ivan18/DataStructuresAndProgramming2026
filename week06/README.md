# Задачи

### Задача 1. Обръщане на всяка група от k елемента

Да се напише функция, която обръща всяка група от `k` елемента в свързан списък. Ако `k` не е делител на броя на елементите в списъка, последната група да остане непроменена.

Не трябва да променяте стойностите на елементите — можете да работите само с указатели.

![Обръщане на групи](https://assets.leetcode.com/uploads/2020/10/03/reverse_ex1.jpg)

```text
Input:  head = [1,2,3,4,5], k = 2    Output: [2,1,4,3,5]
Input:  head = [1,2,3,4,5], k = 3    Output: [3,2,1,4,5]
Input:  head = [1,2,3,4,5], k = 1    Output: [1,2,3,4,5]
Input:  head = [1], k = 1            Output: [1]
```

**Ограничения:**

- Броят на възлите `sz` е в диапазона [1, 5000].
- 0 <= Node.val <= 1000
- 1 <= k <= sz

Може ли задачата да се реши с O(1) допълнителна памет?

### Задача 2. Палиндром

Да се напише функция, която проверява дали свързан списък е палиндром.

![Палиндром](https://assets.leetcode.com/uploads/2021/03/03/pal1linked-list.jpg)

```text
Input:  head = [1,2,2,1]    Output: true
Input:  head = [1,2]        Output: false
```

**Ограничения:**

- Броят на възлите е в диапазона [1, 10<sup>5</sup>].
- 0 <= Node.val <= 9

Може ли задачата да се реши за O(n) време и O(1) допълнителна памет?

### Задача 3. Премахване на последователности със сума нула

Даден е свързан списък. Премахвайте последователности от съседни възли, чиято сума е `0`, докато в списъка не останат такива последователности. Върнете началото на получения списък.

Ако има няколко възможни отговора, върнете кой да е от тях.

```text
Input:  head = [1,2,-3,3,1]     Output: [3,1]      (отговорът [1,2,1] също е верен)
Input:  head = [1,2,3,-3,4]     Output: [1,2,4]
Input:  head = [1,2,3,-3,-2]    Output: [1]
```

**Ограничения:**

- Броят на възлите е в диапазона [1, 1000].
- -1000 <= Node.val <= 1000

### Задача 4. Пренареждане на списък

Напишете функция, която пренарежда свързан списък по зададен начин за линейно време.

Ако представим списъка като:

```text
L0 -> L1 -> ... -> Ln-1 -> Ln
```

пренареждаме елементите му по следния начин:

```text
L0 -> Ln -> L1 -> Ln-1 -> L2 -> Ln-2 -> ...
```

![Пренареждане](https://assets.leetcode.com/uploads/2021/03/04/reorder1linked-list.jpg)

```text
Input:  head = [1,2,3,4]      Output: [1,4,2,3]
Input:  head = [1,2,3,4,5]    Output: [1,5,2,4,3]
```

**Ограничения:**

- Броят на възлите е в диапазона [1, 5 * 10<sup>4</sup>].
- 1 <= Node.val <= 1000

### Задача 5. Вмъкване в цикличен сортиран списък

По даден произволен елемент от цикличен свързан списък, сортиран възходящо, напишете функция, която добавя елемент в списъка така, че той да остане сортиран. Ако има няколко подходящи места, изберете сами къде да вмъкнете новия елемент.

![Цикличен сортиран списък](https://assets.leetcode.com/uploads/2019/01/19/example_1_before_65p.jpg)

```text
Input:  head = [3,4,1], insertVal = 2
Output: [3,4,1,2]
```

Подаден е възелът със стойност 3, а новият възел трябва да се вмъкне между 1 и 3. След вмъкването се връща същият възел 3.

![След вмъкването](https://assets.leetcode.com/uploads/2019/01/19/example_1_after_65p.jpg)

**Ограничения:**

- Броят на възлите е в диапазона [0, 5 * 10<sup>4</sup>].
- -10<sup>6</sup> <= Node.val <= 10<sup>6</sup>
- -10<sup>6</sup> <= insertVal <= 10<sup>6</sup>

### Задача 6. Четни и нечетни позиции

Даден е едносвързан списък. Пренаредете го така, че всички елементи на нечетни позиции да са първи, последвани от елементите на четни позиции, и върнете пренаредения списък.

За да е по-интересно, първият елемент се смята за елемент на нечетна позиция, вторият — на четна, и т.н.

Използвайте O(1) допълнителна памет и O(n) време.

```text
Input:  head = [1,2,3,4,5]        Output: [1,3,5,2,4]
Input:  head = [2,1,3,5,6,4,7]    Output: [2,3,6,7,1,5,4]
```

**Ограничения:**

- Броят на възлите `n` е в диапазона [0, 10<sup>4</sup>].
- -10<sup>6</sup> <= Node.val <= 10<sup>6</sup>

### Задача 7. Разделяне по стойност

Даден е едносвързан списък и число `x`. Пренаредете списъка така, че всички елементи със стойност, по-малка от `x`, да са преди елементите със стойност, по-голяма или равна на `x`. Относителният ред на елементите в двете части трябва да се запази.

![Разделяне](https://assets.leetcode.com/uploads/2021/01/04/partition.jpg)

```text
Input:  head = [1,4,3,2,5,2], x = 3    Output: [1,2,2,4,3,5]
Input:  head = [2,1], x = 2            Output: [1,2]
```

**Ограничения:**

- Броят на възлите е в диапазона [0, 200].
- -100 <= Node.val <= 100
- -200 <= x <= 200

### Задача 8 (от контролно). Разместване на половините

Даден е списък `l` с `n` елемента. Да се дефинира функция `shuffle()`, която получава адреса на първия елемент на списъка и пренарежда възлите така, че **елементите от втората половина на списъка да се преместят в началото, но в обратен ред**.

При списъци с нечетен брой елементи считаме средния елемент за принадлежащ към първата половина.

```text
L1 -> L2 -> L3 -> L4 -> L5   ->   L5 -> L4 -> L1 -> L2 -> L3
```

### Задача 9 (от контролно). Изравняване на стекове

Даден е списък `l` с елементи стекове. Да се дефинира функция `equalize(l)`, която размества елементите на стековете така, че **да няма два стека в `l` с разлика в броя на елементите, по-голяма от 1**.

```text
Вход:                          Изход:

5 -> 4 -> 3 -> 2 -> 1          5 -> 4 -> 3
|                              |
v                              v
7 -> 6                         7 -> 6 -> 1
|                              |
v                              v
11 -> 10 -> 9 -> 8             11 -> 10 -> 9
|                              |
v                              v
12                             12 -> 2 -> 8
```
